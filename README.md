📌 Project Overview

This project is an interactive Telco Customer Churn Analysis Dashboard built using Microsoft Power BI. It analyzes customer demographics, account details, tenure, credit score, geography, and churn behavior to help businesses identify churn patterns, monitor key performance indicators (KPIs), and support data-driven customer retention strategies.

The dashboard enables stakeholders to explore customer trends through interactive visualizations, helping them understand the factors influencing customer churn and improve business decision-making.

✨ Features
📊 Interactive customer churn dashboard
📈 KPI cards for key business metrics
👥 Customer behavior analysis
🌍 Geographic distribution of customers
📉 Churn rate and customer trend analysis
💳 Credit score and account balance analysis
🏦 Product usage insights
🎯 Dynamic filtering and drill-down capabilities
📍 Geographic map visualization
📌 Business performance monitoring using KPIs
🛠️ Tech Stack
Microsoft Power BI Desktop

Interactive Data Visualization

⚙️ Installation & Setup
Clone this repository.
git clone https://github.com/penugondarohith/Powerbi.git
Open Project.pbix using Microsoft Power BI Desktop.
If prompted, reconnect the Excel dataset (Customer churn.xlsx).
Refresh the data.
Explore the interactive dashboard.
▶️ Usage
Open the Power BI report (Project.pbix).
Navigate through the dashboard pages.
Use slicers and filters to analyze customer data.
Explore customer demographics, churn trends, geographic distribution, and KPIs.
Use the insights to identify customer retention opportunities and business performance trends.
